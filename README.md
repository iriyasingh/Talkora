# 💬 Talkora — Real-Time Chat Application


## 📌 Overview

**Talkora** is a modern real-time chat application designed to provide seamless communication between users. It enables secure authentication, one-to-one messaging, user profiles, and live chat functionality with a clean and responsive interface.

Built with modern web technologies, Talkora focuses on delivering a smooth messaging experience with real-time updates, unread message tracking, and efficient user management.

---

## ✨ Features

### 🔐 Authentication

* Secure user signup and login
* Cookie-based authentication
* Protected routes
* User profile management

### 💬 Real-Time Messaging

* One-to-one conversations
* Instant message delivery
* Powered by Stream Chat API
* Message history and synchronization

### 🔔 Smart Chat Indicators

* Unread message detection
* Real-time unread status updates
* Chat notification indicators
* Read/unread message tracking

### 👤 User Experience

* User avatars and profiles
* Responsive sidebar navigation
* Modern UI design
* Smooth navigation experience

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/your-username/Talkora.git
```

### Install Dependencies

Frontend:

```bash
cd frontend
npm install
```

Backend:

```bash
cd backend
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file in the backend folder:

```env
PORT=5001

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

STREAM_API_KEY=your_stream_api_key

STREAM_API_SECRET=your_stream_api_secret
```

---

## 🚀 Running the Application

Start Backend:

```bash
npm run dev
```

Start Frontend:

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
